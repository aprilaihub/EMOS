Help & FAQ

How EMOS works, and where to go next. Still stuck? Ask the assistant below.

An Information Unit (IU) is a single building block: a database (retrieve known structures), a generator (propose new ones), or a predictor (estimate a property). Each exposes one standard action, so they all plug into the same workflow.

A Feature is a ready-made workflow that composes one or more IUs into an end-to-end task, like the Database Extractor or Stability Consensus. Pick a Feature, select the units it should use, set the parameters, and run.

Results come back as a ranked table of candidates, an interactive plot of band gap with uncertainty, and a real 3D crystal structure you can rotate. Pin the ones worth keeping with the pin icon.

Open it from the sidebar. Drag any unit from the left onto the canvas, then connect an output port (right of a node) to an input port (left). Matching colours connect. Press Run Pipeline to execute the whole graph.

The full reference lives on the Documentation page, covering every Information Unit, Feature and the node editor in detail.
