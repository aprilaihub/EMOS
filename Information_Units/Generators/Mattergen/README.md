# Mattergen Generator

Mattergen (Microsoft's generative model for crystal structures) generator.

## Overview

Generate crystal structures using Microsoft's diffusion-based generative model.

## Key Methods

- `info()`: Returns description and capabilities of Mattergen generator
- `generate(params)`: Generates crystal structures based on input parameters
