# Molgan Generator

MolGAN (Molecular Generative Adversarial Network) generator.

## Overview

Generate molecular structures using GAN-based approach for drug discovery and materials.

## Key Methods

- `info()`: Returns description and capabilities of MolGAN generator
- `generate(params)`: Generates molecular structures based on input parameters
