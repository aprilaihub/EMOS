# Conddfcvae Generator

Conditional Deep Feature Consistent VAE for materials generation.

## Overview

Generate novel crystal structures using conditional variational autoencoder with deep feature consistency.

## Key Methods

- `info()`: Returns description and capabilities of Cond-DFC-VAE generator
- `generate(params)`: Generates new materials structures based on input parameters
