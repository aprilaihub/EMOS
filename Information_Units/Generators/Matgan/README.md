# Matgan Generator

MatGAN (Generative Adversarial Network for materials) generator.

## Overview

Generate novel crystal structures using GAN architecture trained on materials data.

## Key Methods

- `info()`: Returns description and capabilities of MatGAN generator
- `generate(params)`: Generates new materials using GAN based on input parameters
