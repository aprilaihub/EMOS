# Gnome Generator

GNoME (Graph Networks for Materials Exploration) generator.

## Overview

Generate novel materials using Google DeepMind's graph network-based deep learning framework.

## Key Methods

- `info()`: Returns description and capabilities of GNoME generator
- `generate(params)`: Generates new materials structures based on input parameters
