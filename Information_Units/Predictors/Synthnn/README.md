# Synthnn Predictor

SynthNN (Synthesis Neural Network) predictor.

## Overview

Predict materials synthesis conditions and feasibility using neural network trained on synthesis data.

## Key Methods

- `info()`: Returns description and capabilities of SynthNN predictor
- `predict(params)`: Predicts synthesis conditions and feasibility based on input parameters
