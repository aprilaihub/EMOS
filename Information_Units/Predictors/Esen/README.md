# Esen Predictor

eSEN (Enhanced Structure-Energy Network) predictor.

## Overview

Predict advanced materials properties using enhanced structure-energy neural network approach.

## Key Methods

- `info()`: Returns description and capabilities of eSEN predictor
- `predict(params)`: Predicts materials properties based on input parameters
