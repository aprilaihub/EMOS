# M3gnet Predictor

M3GNet (Materials 3-body Graph Network) predictor.

## Overview

Predict universal materials properties using 3-body graph network architecture.

## Key Methods

- `info()`: Returns description and capabilities of M3GNet predictor
- `predict(params)`: Predicts materials properties based on input parameters
