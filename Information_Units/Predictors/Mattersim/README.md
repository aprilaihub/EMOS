# Mattersim Predictor

MatterSim (Microsoft's MLIP for inorganic crystals) predictor.

## Overview

Predict properties of inorganic crystals using machine learning interatomic potential.

## Key Methods

- `info()`: Returns description and capabilities of MatterSim predictor
- `predict(params)`: Predicts crystal properties based on input parameters
