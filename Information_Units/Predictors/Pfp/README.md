# Pfp Predictor

PFP (Physics-informed neural network) predictor.

## Overview

Predict materials properties using physics-informed neural network approach that incorporates domain knowledge.

## Key Methods

- `info()`: Returns description and capabilities of PFP predictor
- `predict(params)`: Predicts properties using physics-informed approach based on input parameters
