# Deepmd Predictor

DeepMD (Deep Potential Molecular Dynamics) predictor.

## Overview

Predict accurate force fields and molecular dynamics properties using deep learning potentials.

## Key Methods

- `info()`: Returns description and capabilities of DeepMD predictor
- `predict(params)`: Predicts force fields and MD properties based on input parameters
