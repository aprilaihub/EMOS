# Cod Database

Interface to COD (Crystallography Open Database) via OPTIMADE.

## Overview

Access crystallographic structures from the open-access COD repository and save them as CIF files.

## Key Methods

- `info()`: Returns description and capabilities of COD database
- `retrieve(params)`: Retrieves crystallographic data based on input parameters
