# Jarvis Database

Interface to JARVIS (Joint Automated Repository for Various Integrated Simulations).

## Overview

Access diverse materials data from NIST's JARVIS database including DFT, ML, and experimental data.

## Key Methods

- `info()`: Returns description and capabilities of JARVIS database
- `retrieve(params)`: Retrieves materials data based on input parameters
