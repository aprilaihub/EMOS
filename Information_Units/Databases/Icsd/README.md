# Icsd Database

Interface to ICSD (Inorganic Crystal Structure Database).

## Overview

Access high-quality inorganic crystal structures from ICSD.

## Key Methods

- `info()`: Returns description and capabilities of ICSD database
- `retrieve(params)`: Retrieves inorganic crystal structures based on input parameters
