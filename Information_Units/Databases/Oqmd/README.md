# Oqmd Database

Interface to OQMD (Open Quantum Materials Database).

## Overview

Access DFT-calculated structures and thermodynamic properties from OQMD.

## Key Methods

- `info()`: Returns description and capabilities of OQMD database
- `retrieve(params)`: Retrieves DFT calculated data based on input parameters
