# Information Units

Information Units (IUs) provide data and calculations to EMOS. Each IU is a Python implementation registered in a factory.

## Types

- [Databases](information-units/databases/index.md) find existing materials.
- [Generators](information-units/generators/index.md) create new crystal structures.
- [Predictors](information-units/predictors/index.md) calculate material properties.

See the [Database IU tutorial](tutorials/tutorial_database_iu.md), [Generator IU tutorial](tutorials/tutorial_generator_iu.md), and [Predictor IU tutorial](tutorials/tutorial_predictor_iu.md) for examples.
