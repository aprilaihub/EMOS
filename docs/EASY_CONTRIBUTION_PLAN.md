# EMOS Easy Contribution Plan (Minimal)

## Goal

Make it easy for developers to add new Information Units (IUs) and Features without confusion.

## What We Will Do

1. Keep one clear contribution path in `CONTRIBUTING.md`.
2. Provide simple starter templates for:
   - new IU
   - new Feature
3. Define minimum required checks for a new contribution:
   - basic test for new code
   - registration/factory wiring check
   - short docs update for the new IU/Feature
4. Add a small PR checklist so contributors know when they are done.

## Minimal Deliverables

- Updated `CONTRIBUTING.md` with step-by-step commands.
- One IU template and one Feature template.
- One short “minimum quality” checklist for PRs.

## Done Criteria

- A new contributor can add one IU or one Feature using docs only.
- They can run the minimum checks and open a clean PR.
