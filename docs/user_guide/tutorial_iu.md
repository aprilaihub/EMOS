# Information Unit Tutorials

EMOS provides three Information Unit (IU) types. Choose the tutorial that matches the IU you want to add:

- [Database IU Tutorial](tutorial_database_iu.md): add a database IU that retrieves CIF structures.
- [Generator IU Tutorial](tutorial_generator_iu.md): add a generator IU that produces CIF structures.
- [Predictor IU Tutorial](tutorial_predictor_iu.md): add a predictor IU that analyzes input CIF structures.

Each tutorial follows the same end-to-end flow: register the IU, generate scaffolding, implement the backend method, configure property mappings, add frontend wiring, verify the result, and clean up the demo IU.
