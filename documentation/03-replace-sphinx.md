# Plan 3: Replace Sphinx

## Goal

Make VitePress the documentation system and remove the old Sphinx setup.

## Steps

1. Confirm that all required documentation is available in Markdown.
2. Confirm that the VitePress site builds successfully.
3. Update the README with the new documentation commands and link.
4. Remove the Sphinx configuration and dependencies.
5. Remove obsolete Sphinx and reStructuredText files.
6. Update CI or deployment settings to build VitePress.

## Done when

- VitePress is the only documentation build system.
- Documentation is written in Markdown.
- The documentation builds in CI.
- The old Sphinx files and commands are no longer needed.
