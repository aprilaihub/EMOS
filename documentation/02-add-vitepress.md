# Plan 2: Add VitePress

## Goal

Use VitePress to display the Markdown documentation as a simple documentation website.

## Steps

1. Add VitePress to the project.
2. Use the Markdown files from Plan 1 as the content.
3. Add simple navigation for the introduction, IUs, Features, and contribution pages.
4. Add commands to run and build the documentation locally.
5. Check that the pages and links work.

Do not duplicate the documentation. VitePress should use the existing Markdown files.

## Done when

- The documentation opens as a local website.
- Users can navigate to all main pages.
- The documentation builds successfully.
