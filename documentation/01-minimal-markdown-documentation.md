# Plan 1: Minimal Markdown Documentation

## Goal

Create simple Markdown documentation that explains EMOS and helps contributors understand its components.

## Pages

Create these pages:

- `index.md` - Short introduction to EMOS
- `information-units.md` - How Databases, Generators, and Predictors work
- `features.md` - How Features work
- The Contribution section in `index.md` - How to add an IU or Feature

## Component documentation

Each IU and Feature should have a simple page that explains:

- What it does
- What inputs it needs
- What it returns
- How to use it

Use the Python implementation and its docstrings as the technical reference.

## Done when

- The main workflow is explained in Markdown.
- Current IUs and Features are documented.
- Contributors can follow the contribution page.
